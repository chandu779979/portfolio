  - **Smart Waste Reporting & Management:** Full-stack civic reporting application built with Flask, PostgreSQL, and Brevo API.

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/chandu779979/portfolio.git
   cd portfolio
   ```
2. Open `index.html` directly in your browser or run a local server:
   ```bash
   # Windows launcher:
   start_server.bat

   # Or via Python:
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
